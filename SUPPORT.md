# Support

- **Quick help** — open a GitHub **Discussion** (Q&A category) or an **Issue**.
- **Bugs** — include the 🩺 Self-check output from the footer button (version, controls, ids) + steps to reproduce + browser.
- **Feature ideas** — open a Discussion with the `ideas` label, or an Issue tagged `enhancement`.
- **The app is offline & local** — no account, no telemetry. If something misbehaves, a hard refresh + 💾 Save .json first is the best first step.

We aim to reply within a few days.
